Accounting firm · 2026

HUB Contábil: an automation platform for an accounting firm

Problem
Company analyses, balance sheet reading, vacation pay calculations and client file processing were 100% manual. Each one took the team days of reading documents and re-keying data.
What I did
Mapped each workflow with the people who ran it, then designed and built an internal web platform where AI reads the files clients send, extracts what matters and returns structured results ready for review.
Scope
Used daily across the firm's accounting team, serving 100+ client companies and individuals. Integrations with the firm's accounting system (Domínio / Thomson Reuters) are being scoped.
Processes that took 2–3 days now run in about 15 minutes, according to the team that uses it.

How I work

The same loop, whether the workflow is a monthly tax routine or a sales process across branches.

Diagnose

Sit with the people doing the work and map every step, input and handoff as it really happens.

Simplify

Remove steps before automating them. Standardise inputs and outputs.

Automate

Build the solution: AI for reading and judgement, code for the rest, people kept in the loop where it matters.

Measure

Track time, errors and adoption, then iterate with the team that uses it.
